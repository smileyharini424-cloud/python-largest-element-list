# Find the Largest Element in a List

## Explanation

This Python program accepts a list of numbers and finds the largest element in the list.

## Problem Statement

Write a Python program to input a list of numbers and find the largest element without manually sorting the list.

## Features

* Accepts multiple numbers.
* Stores numbers in a list.
* Finds the largest value.
* Displays the result.

## How It Works

1. Read numbers from the user.
2. Store them in a list.
3. Use the `max()` function to find the largest element.
4. Display the largest element.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `split()`
* `map()`
* `max()`

## Program Flow

Input → Create List → Find Maximum → Display Result

## Sample Input

```text
12 45 7 89 23
```

## Sample Output

```text
Largest element: 89
```

## Space Complexity
